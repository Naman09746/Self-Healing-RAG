Project Overview

The Self-Healing Multi-Agent RAG system is a production-grade Retrieval-Augmented Generation platform that combines LangGraph orchestration, multi-agent architecture, autonomous hallucination detection, and a complete evaluation framework with RAGAS metrics.


The system features 8 specialized agents — Planner, Retrieval (hybrid dense + sparse), Generation, Critic (hallucination detection), Healer (self-correcting retrieval), Memory (session + episodic), and Evaluation — orchestrated via a state machine graph with feedback loops. When the Critic detects hallucinations, the Healer rewrites the query and re-retrieves, creating an autonomous self-healing cycle.

🔄 Critic Agent — Hallucination Detection

The Critic agent is the system's quality gate. It:

  1. Extracts claims from the generated answer via LLM
  2. Verifies each claim against retrieved context
  3. Assigns grounding scores per claim (0.0–1.0)
  4. Returns a binary verdict: is_hallucinated flag
Scoring: Faithfulness = mean(claim_scores)
Threshold: GROUNDING_THRESHOLD = 0.7

LangGraph Workflow & State Machine

Compiled graph with 8 nodes, conditional edges, and bounded state

📐 State Definition (RAGState)

FieldTypeDescription
querystrUser's original question
rewritten_querystrHealing-rewritten variant
retrieved_chunksBoundedListMax 20 chunks (evicts oldest)
generated_answerstrLLM's final answer
grounding_scorefloatCritic's faithfulness score
retry_countintNumber of healing attempts
error_logBoundedListMax 10 error entries
trace_idstrOTel trace correlation

🔀 Edge Routing

  • should_heal(): If grounding_score < 0.7 AND retry_count < 3 → route to healing loop
  • max_retries_exceeded: If healing exhausted → force output with degradation flag
  • output_ready: If critic passes → final output

📐 RAGAS Metrics Integrated

MetricDescriptionRange
Faithfulness Are answer claims supported by retrieved context? 0.0 – 1.0
Answer Relevancy Does the answer address the question? 0.0 – 1.0
Context Precision Are retrieved chunks relevant to the query? 0.0 – 1.0
Fallback: When RAGAS is not installed, the system falls back to heuristic scoring (overlap-based) — ensuring the pipeline always runs.
